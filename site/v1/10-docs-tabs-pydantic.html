Pydantic — Python Installation & Lockfile Pinning

Data validation using Python type hints, backed by a Rust core validator. Supported Python versions: >=3.10.

Install Package

Choose pip for quick local prototyping or open the uv / requirements.txt (Pinned) tab for reproducible CI deployments.

Install the latest compatible release via pip:

pip install pydantic

Pin the exact current PyPI release in uv or requirements.txt:

uv add "pydantic==2.14.4"

# requirements.txt
pydantic==2.14.4

Quick Validation Example

from pydantic import BaseModel

class Invoice(BaseModel):
    account_id: int
    currency: str = "USD"
    amount_cents: int
